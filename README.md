# Rime Skins · 小狼毫搜狗皮肤扩展

基于 [rime/weasel](https://github.com/rime/weasel) 的非官方扩展，为小狼毫提供搜狗静态横版皮肤导入和管理窗口。

当前为 **0.1.0-alpha.2**，基于 **Weasel 0.17.4**，面向 **Windows x64 TSF**。

## 功能

- 导入支持的 `.ssf`，预览背景、切换皮肤、恢复默认和撤销切换。
- 独立皮肤库，日常换肤无需管理员权限；管理器按需运行。
- 图片透明背景、九宫格拉伸、候选点击区域适配。
- 优化首次绘制、字体资源与背景缓冲复用。
- 跟踪上游稳定版，生成更新草稿 PR，冲突时报告；人工审核后合并与发布。

**支持范围有限**：静态 `Scheme_H1` 拉伸布局；暂不支持动画、平铺、特殊布局、竖版及独立状态栏。
不是所有搜狗皮肤都能原样使用。32 位应用与 ARM64 尚未提供改版模块。

## 使用

先安装官方 Weasel 0.17.4，再安装本项目的匹配扩展包。安装程序需要管理员 PowerShell 7；
日常打开「皮肤管理」即可导入和切换，不需要 Python。
