# 安装与换肤

这是小狼毫的非官方静态皮肤扩展。首个版本为 alpha，基于 Weasel 0.17.4。

## 安装前提

- Windows x64，已经安装官方 Weasel 0.17.4，安装路径只含 ASCII 字符。
- 初次安装/升级/恢复需要管理员权限和 PowerShell 7。
- 当前包只替换 **64 位 TSF**；32 位程序、ARM64 和 IMM 不在本版本验收范围。
- 安装包不附带第三方皮肤。自行准备有权使用的 `.ssf` 文件。

## 安装

下载本项目提供的包并解压。在解压目录打开管理员 PowerShell 7，运行：

```powershell
./install-extension.ps1 Install
```

安装器验证基础版本和包内 SHA-256，复制到官方安装目录的独立 `skin-extension` 子目录，
记录旧 TSF 注册路径，再启用新模块。哈希用于检测包损坏，不代表数字签名。
关闭并重新打开需要使用输入法的应用；旧进程可能仍加载旧 DLL。

安装不会改写 Rime YAML、快捷键、词库，也不会覆盖原 DLL。
首次安装会切换输入法服务，运行前请先完成正在输入的组词。

## 换肤

1. 在新版小狼毫托盘菜单打开「皮肤管理」，或者双击安装目录中的 `WeaselSkinManager.exe`。
2. 点击「导入 .ssf…」，选择文件并查看背景预览。
3. 点击「应用皮肤」，回到输入框重新组词。
4. 「恢复默认」恢复原来的 Rime 配色；「撤销切换」在最近两次状态间切换。

日常换肤不需要管理员权限、Python 或重新部署词库。管理器关闭后不常驻。
换肤会通知已运行的候选窗口；受权限隔离影响的窗口会在后续输入时检查配置。
预览展示背景，文字位置和候选数量以实际输入为准。

移除皮肤会移到用户皮肤库的 `.trash` 目录；正在使用的皮肤不能移除。
如果移除了上一次皮肤，撤销可能回到默认配色；可从原文件重新导入。

## 支持范围

支持 ZIP 格式 SSF 中的静态 `Scheme_H1`，PNG/BMP 背景、九宫格拉伸、透明通道和基本文字颜色。
只支持 `layout_horizontal` / `layout_vertical` 的模式 `0`。
不支持所有搜狗皮肤：动画、平铺、特殊布局、竖版、独立状态栏以及搜狗特有按钮未实现。
不兼容的布局会拒绝导入；支持包中的其他未支持组件不会导入。
输入方案需使用横向候选布局，竖向或隐藏候选时沿用原渲染。

## 登录后入口

已经安装改版渲染模块的用户，可以单独安装或更新管理器，在普通 PowerShell 7 中运行：

```powershell
./install-manager.ps1
```

这会把管理器复制到当前用户的本地应用目录，并添加开始菜单「Rime Skin Manager」（皮肤管理）。
不修改 TSF 注册或服务。仅安装此管理器，不能让官方原版小狼毫显示图片皮肤。
如果运行环境重定向了本地应用目录，可通过 `-InstallRoot` 指定用户可访问的目录；
增加 `-DesktopShortcut` 可同时创建桌面快捷方式。管理器及 `manager-runtime` 应一起保留。

此 alpha 安装器保留官方自启动设置。重新登录后，官方服务的菜单可能没有「皮肤管理」。
独立管理器仍可直接使用；也可启动安装器输出目录内的新版 `WeaselServer.exe`，恢复新版托盘菜单。
可为 `WeaselSkinManager.exe` 创建快捷方式。不要移动或单独复制它；同目录的 `manager-runtime` 必须保留。

## 恢复与更新

```powershell
./install-extension.ps1 Status
./install-extension.ps1 Restore
```

Restore 需要管理员权限，恢复安装前的 TSF 注册路径和官方服务，保留皮肤、设置和程序副本。
它不是卸载官方小狼毫。恢复后同样要重开应用。

安装器在注册被其他安装器更改后会拒绝覆盖。官方升级可能重置 TSF 注册；升级前建议先 Restore，
等本项目发布匹配新上游版本的包后再安装。不要把旧包强装到新版本。

皮肤库在 Rime 用户目录的 `skins` 下，当前激活记录是 `sogou-skin.ini`。
上游更新经草稿 PR、构建和真实输入验证后才适合发布，本项目不自动下载覆盖安装。
