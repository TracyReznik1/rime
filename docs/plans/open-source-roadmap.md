# 后续路线

当前 alpha 已包含静态 H1 导入、独立皮肤管理器、x64 渲染、安装恢复脚本和上游更新草稿 PR 工作流。

后续重点：

1. 在干净 Windows 环境完成安装、恢复与实际输入验收，提供正式可下载包。
2. 完成 x86 TSF 与 32 位应用验证，再考虑 ARM64。
3. 提供安装向导、开始菜单入口和可选择的自启动整合。
4. 增加更多真实 SSF 兼容样本和高 DPI/多屏测试，保持素材授权边界。
5. 逐个审核上游更新，独立整理通用性能改动以便贡献上游。

上游更新不自动合并；每次发布仍需检查实际 DLL 加载、候选输入、皮肤恢复和固定机器性能。
动画、竖版和独立状态栏不是首个版本的前提。
